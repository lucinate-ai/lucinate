## Room shared state (uncommitted, 2026-11-04)

A room member gets only a bounded delta of the transcript plus a fixed rule
frame, so every member rediscovered the repo and a room spent its first round
establishing where it stood. Four slices close that, all client-side:

1. **Brief** — `internal/rooms/brief.go`. `BuildBrief(repoPath)` reads branch,
   HEAD, dirty count, AGENTS.md bullets, README, unchecked `openspec` tasks and
   the newest `docs/handoff` file; `Markdown()` is deterministic (no timestamps,
   ≤6000 B) and `Digest()` is the first 12 hex of its sha256. `WriteBrief` writes
   `<roomdir>/brief.md` atomically. `client.go:305` prepends
   `brief: <path> sha=<digest>` to the room's first message; a brief error never
   blocks the send. Members read the file instead of exploring.
2. **Ledger** — `internal/rooms/ledger.go`. Append-only `<roomdir>/work.jsonl`
   (`Claim{Task,Owner,Status,Artifact,Bytes,Note,At}`), `Board()` for a ≤12-line
   table, `DuplicateOf()` for an artifact already done by another owner,
   `EnsureLedger()` so the file the brief points at really exists.
3. **Evidence** — `internal/rooms/evidence.go`. `VerifyReply(dir, owner, text)`
   re-reads every `HANDOFF <path> bytes=<n>` receipt (`sharedir.go` already had
   the verifier, nothing called it) and returns `none | verified | failed |
   duplicate`. The TUI computes it once per arriving member message
   (`rooms.go:760-790`), caches it by event key and renders one dim `✓`/`✗` row
   under the message (`rooms_ux.go:1141-1175`), counted in the pager's rows.
4. **Pulse** — `internal/rooms/pulse.go` + `p` key. When the room is idle and
   the composer is empty, `p` posts the board plus "120 words: stance, what you
   don't know, what you take; do not work this round". A new user message opens
   a NEW discussion, so the gateway's 3-round / 10-message budget restarts —
   that is what makes a long discussion possible. While the room works, `p`
   refuses and says so.

## What the room actually enforces (don't re-derive it)

Source: `docs/room-rules.md`, which quotes the gateway. Short version:

- Round 0 is the user's message: `@mention` picks the responders, **no mention means everyone**.
- Rounds 1–2 are opt-in: a member is pulled in only when a **peer** cites them by handle, and only
  if they have not been heard from since.
- Caps: 3 rounds, 10 member messages, 24 transcript lines per turn, 64 KiB per reply, roster 2–6.
- Silence is allowed: a member may reply exactly `(pass)`; a round where nobody speaks ends the
  discussion as `settled / silent_round`; hitting a cap ends it `bounded / max_rounds|max_messages`.
- Members see each other's replies (republished as a user-role message), so the room is one shared
  transcript, not private channels.
- The client's routing modes are **text shaping only** (`internal/rooms/routing.go`): it can add a
  mention, never forbid a peer pull. A hard prohibition needs a gateway change.

## Environment, if you want to reproduce in five minutes

The app needs a real gateway the client can dial as `http://localhost:9119/api/ws?token=…`.

```sh
# 1. gateway (token must match the one stored for the connection)
HERMES_DASHBOARD_SESSION_TOKEN=lucinate-live setsid hermes dashboard --port 9119 --skip-build --no-open &
# 2. the client's stored secret (0600): ~/.lucinate/secrets/secrets.json
#    {"apiKeys": {"<connection-id>": "lucinate-live"}}  — id from ~/.lucinate/connections.json
# 3. run it
cd /home/hermes/projects/lucinate && ./lucinate
```

Driving the TUI through an Orca terminal: `enter` is `text: "\r"` with `enter: false`, down arrow
is `"\u001b[B"`, space is `" "`, PgUp is `"\u001b[5~"`, ctrl+c is `"\x03"`. Read the screen back —
`accepted: true` means "accepted", not "delivered".

## Traps worth remembering

- A dashboard started from an agent shell dies when the turn is torn down; start it inside the
  Orca pty. The token is env-var-borne: restart the dashboard without it and the client will ask
  for a new token.
- A blank picker body is a bubbles plumbing bug, not a terminal size: the visible set comes from
  the filter, so `SetFilterText("")` must run before `SetFilterState(list.Filtering)`.
- `model.options` sends `providers[].models` as plain strings; `session.list` rows must be
  `derivedTitle` / `lastMessagePreview` (that is the TUI's contract, `internal/tui/sessions.go`).
- Peer-pull wording is deliberately "into the next round", not "round 2": the header counts rounds
  that already produced messages, so a number would contradict it mid-turn.
- `.rooms/` is gitignored and accumulates test directories. One is left in this checkout by another
  session (`companion-content-creator-freelancer-3`) — not ours, do not delete another agent's
  evidence. The directories from this session's runs were removed after their handoff claims were
  checked (`HANDOFF … bytes=` matched `stat` byte for byte).
- `docs/rooms-live-check.md` was written by another agent in this worktree and is **untracked** and
  unfinished (it says so itself: "PLACEHOLDER live TUI evidence"). Decide with the owner whether it
  lands, gets finished, or goes.
